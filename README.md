# Лабораторная работа №2. Тема "Техногик и обзорщик гаджетов".

Стилизация персональной веб-страницы вымышленного Техноблогера Громанцева Григория, выполненная в
рамках лабораторной работы по предмету "Web-технологии".

## Краткое описание мини-проекта
Вёрстка данной страницы "О себе" было произведено на **HTML5**, по стандарту **W3C**.
Также был воспроизведен внешний вид страницы в стиле "**Хай-тек**" с помощью **CSS**.
Страница содержит в себе:
* Краткая информация "О себе", с портретом человека;
* Раздел с опубликованными обзорами;
* Форму обратной связи.

## Изменения 
* Аватар техноблогера помещён в отдельную папку "files";
* Карточки навыков были стилизованы под стиль "**Металлических пластин**";
* При наведение на кнопку и карточки навыков, в области обратной связи добавлено **свечение**;
* Каждая секция имеет **отдельную рамку**. Фоновый цвет рамок отличается от основного фона.
